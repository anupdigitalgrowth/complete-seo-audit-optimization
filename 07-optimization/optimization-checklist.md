# SEO Optimization Master Checklist

Use this operational checklist to track implementation progress across Technical SEO, On-Page SEO, and Analytics Measurement steps.

---

## Technical SEO

- [ ] **Crawlability:** Resolve 404 errors, fix broken internal links, and eliminate redirect loops.
- [ ] **Indexability:** Verify meta robots tags and ensure primary URLs are indexable in Google Search Console.
- [ ] **Sitemap:** Update XML sitemaps to include only 200 OK canonical URLs and submit to GSC.
- [ ] **Robots.txt:** Validate crawl directives, ensure CSS/JS asset paths are open, and include sitemap link.
- [ ] **Canonical:** Verify self-referential canonical tags on all indexable pages to prevent duplication.
- [ ] **HTTPS:** Confirm SSL certificate validity, enforcement of 301 HTTPS redirects, and zero mixed content.
- [ ] **Mobile:** Ensure mobile viewport meta tags, readable font sizes, and accessible touch target spacing.
- [ ] **Page Speed:** Compress images to WebP, minify assets, eliminate render-blocking CSS/JS, and pass Core Web Vitals.
- [ ] **Structured Data:** Implement schema markup (Organization, WebSite, Article, LocalBusiness, Product) without errors.

---

## On-Page SEO

- [ ] **Titles:** Rewrite title tags (50-60 chars) to include primary keywords and compelling branding.
- [ ] **Meta Descriptions:** Craft actionable meta descriptions (140-155 chars) with target search intent CTAs.
- [ ] **H1:** Ensure exactly one unique H1 tag containing the primary page keyword per landing page.
- [ ] **H2/H3:** Structure content logically with keyword-optimized subheadings.
- [ ] **URLs:** Clean up URL structures to be lowercase, hyphenated, concise, and keyword-relevant.
- [ ] **Internal Links:** Add contextual internal links with keyword-descriptive anchor text across pages.
- [ ] **Images:** Rename image files, compress below 100KB, and add descriptive ALT text for accessibility.
- [ ] **Content:** Expand thin content, align copy with search intent, and resolve content gaps.

---

## Measurement

- [ ] **GSC:** Verify Google Search Console property ownership, URL inspection, and sitemap tracking.
- [ ] **GA4:** Ensure Google Analytics 4 tracking tag installation and data stream verification.
- [ ] **Conversion Tracking:** Set up key events, form submission goals, and click conversions.
- [ ] **Baseline Metrics:** Record baseline clicks, impressions, CTR, average position, and speed scores.
- [ ] **Reporting:** Compile final before/after audit findings into executive presentation reports.
