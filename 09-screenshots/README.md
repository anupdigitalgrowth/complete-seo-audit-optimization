# Project Screenshots Directory (`09-screenshots/`)

This directory stores visual evidence, before/after audit comparisons, GSC performance graphs, and landing page screenshots referenced throughout the project documentation.

---

## Required Screenshot File Names & Specifications

Please place your actual real-world screenshots into this directory using the following exact file naming convention:

| File Name | Description & Contents | Document Reference Link |
|---|---|---|
| `homepage.png` | Screenshot of audited target website homepage | [`README.md`](../README.md), [`project-brief.md`](../01-project-overview/project-brief.md) |
| `services.png` | Screenshot of core service or landing page | [`README.md`](../README.md), [`content-audit.md`](../03-on-page-seo/content-audit.md) |
| `seo-page.png` | Screenshot of primary target SEO-optimized landing page | [`README.md`](../README.md), [`title-meta-audit.md`](../03-on-page-seo/title-meta-audit.md) |
| `search-console.png` | Screenshot of Google Search Console performance overview | [`README.md`](../README.md), [`gsc-analysis.md`](../06-google-search-console/gsc-analysis.md) |
| `before.png` | Screenshot showing pre-optimization state (errors/unoptimized metadata) | [`README.md`](../README.md), [`before-after.md`](../07-optimization/before-after.md) |
| `after.png` | Screenshot showing post-optimization state (fixed issues/improved scores) | [`README.md`](../README.md), [`before-after.md`](../07-optimization/before-after.md) |

---

> **Guidelines:**
> - Ensure screenshots are captured in high resolution (PNG format recommended).
> - Obscure or blur any private client credentials or sensitive financial data if auditing a private client site.
> - Refer to these image files in Markdown using relative links (e.g., `![GSC Performance](../09-screenshots/search-console.png)`).
